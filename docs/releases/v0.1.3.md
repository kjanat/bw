# v0.1.3

Smaller SDK bundles: the domain and HTML entity tables are now stored as
compressed data. Domain matching and LastPass imports use the same parsers
and complete lookup tables.

Compared with 0.1.2, JavaScript is about 59 kB smaller gzipped. Including the
worker, WASM and new data files, the total saving is about 10 kB.
[Measurements and reproduction](https://github.com/kjanat/vw/blob/v0.1.3/docs/bundle-size.md).

If you bundle the SDK yourself, include the two new `.bin.br` files alongside
the WASM files in `generated/`. Regular npm installations need no changes.
