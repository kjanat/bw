# Security Policy

## Reporting a Vulnerability

Report suspected vulnerabilities privately through either:

- [GitHub private vulnerability reporting](https://github.com/kjanat/vw/security/advisories/new).
- Email: `security+vw [at] kajkowalski [dot] nl`.

Include the affected package and version, steps to reproduce, and the potential
impact. Redact credentials, tokens, and vault contents.

Please avoid public issues or pull requests that disclose vulnerability details.
